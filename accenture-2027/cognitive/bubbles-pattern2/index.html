Bubbles Pattern 2
Hard Mode: Multi-Step Calculations

A tougher version of the Bubbles game. Every bubble holds a multi-step calculation that mixes ×, ÷, + and − with BODMAS and brackets. Same exam pattern: 25 questions, 15 seconds each, tap from the smallest result to the largest. If you can clear this, the real game will feel easy.

How to play

  • Each question shows 3 bubbles, each with a multi-step calculation like 40 − 6 × 6 or (18 + 6) ÷ 4.
  • Solve each one using BODMAS: Brackets first, then ÷ and × (left to right), then + and − (left to right).
  • Tap the bubbles in ASCENDING order: smallest result first, largest last.
  • You have 15 seconds per question. The next question starts automatically.
  • Taps are final. A question is correct only if all 3 taps are in the right order within the time.
