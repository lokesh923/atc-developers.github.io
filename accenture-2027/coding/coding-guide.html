Know the round

The Coding Round

Three questions in 60 minutes: one DSA coding problem, one SQL query and one front-end task. You choose the order. Each answer is graded by hidden test cases, so partially correct code earns partial marks.

QuestionTime planWhat it looks like
C1 · DSA~25 minLeetCode Easy to Medium: arrays, strings, hashing, two pointers, basic recursion, sorting-based problems, number logic. Languages: Java, Python, C++, C#, .NET (some candidates only saw Java, Python and C#).
C2 · SQL~15 minOne query on 1–3 tables: SELECT/WHERE/ORDER BY/GROUP BY/HAVING, joins (main focus), aggregates, DISTINCT, LIMIT, basic subqueries. Exact column aliases are required.
C3 · Frontend~20 minComplete or fix a given HTML/CSS/JS template (HackerRank React-certification style): DOM manipulation, events, form validation, CSS selectors and flexbox, toggling classes, React and Vue basics.
How the coding editor works
Pick a language → a template appears (often a function to complete, sometimes a full program). Run / Compile & Run uses the sample input; Submit runs all test cases, including hidden ones. You can usually submit more than once; the last submission counts.
Important for Java usersThe template may contain a line like throw new Exception(...) or throw new UnsupportedOperationException(). Comment it out or delete it before running, or your code will fail even if the logic is correct. Also keep the class name the template uses (often Main or Solution).
Scoring mindsetHidden tests check edge cases: empty input, one element, all equal values, negative numbers, very large values. A simple solution that handles every edge case beats a clever one that crashes on N = 1.

A1
Read input, print output

Input / Output Templates

Some questions give a function to complete (the platform reads input for you). Others expect a full program that reads from standard input (the keyboard) and prints to standard output. Learn one reading template by heart in your language. Each one below reads N, then N numbers, then a word.

Java — BufferedReader (fast)
import java.util.*;
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());           // line 1: N
        StringTokenizer st = new StringTokenizer(br.readLine());   // line 2: N numbers
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = Integer.parseInt(st.nextToken());
        String word = br.readLine().trim();                        // line 3: a string
        long sum = 0;
        for (int x : a) sum += x;
        System.out.println(sum + " " + word.length());
    }
}
Python — read everything at once
import sys

a = list(map(int, data[1:1 + n]))    # line 2: N numbers
word = data[1 + n]                   # line 3: a string
print(sum(a), len(word))

Function-style template (very common)
You only write the body, for example public static int secondLargest(int[] arr) or def second_largest(arr):. Return the answer; do not print it and do not read input yourself. Keep the given signature unchanged.
Reading tips
Java: Scanner is simple but slow for 105+ numbers, so use BufferedReader. Mixing nextInt() and nextLine() leaves a newline behind, so call an extra nextLine(). Python: input().split() per line, or sys.stdin.read().split() for everything at once.
A2
Will it be fast enough?

Complexity in Practice

Online judges allow roughly 108 simple operations per second (Python is about 10× slower than Java/C++). Use the input limit to choose the algorithm before you code:

Max NNeeded complexityTypical approach
N ≤ 10–20O(2N), O(N!)Recursion, generate all subsets/permutations
N ≤ 1,000O(N²)Two nested loops, brute force over pairs
N ≤ 105 – 106O(N log N) or O(N)Sorting, HashMap, two pointers, sliding window, prefix sums
N ≤ 107O(N)One pass, sieve
N ≤ 1018O(log N) or O(√N)Math, binary representation, digit loops, GCD
Integer overflow
Java/C++/C# int holds about ±2.1 × 109. Sums of many values, products and factorials need long / long long. Python integers never overflow.
Hidden O(N) costs
String += in a loop (use StringBuilder / join), list.remove(x), x in list (use a set), and s.substring inside a loop all cost O(N) each time.
Space
A HashMap or extra array of N items is fine for N ≤ 106. Deep recursion (N > ~104) can overflow the stack, so prefer loops then.

P1

Second Largest Distinct Element

EasyArrays

Given an array of N integers, print the second largest distinct value. If it does not exist (all values equal, or N = 1), print -1.

Input: Line 1: N. Line 2: N integers.

Sample inputOutput
6
12 35 1 10 34 1
34
3
5 5 3
3
Approach
  1. Keep two variables: first (largest) and second, both starting at the smallest possible value.
  2. For each x: if x > first, the old first becomes second and x becomes first.
  3. Else if x < first and x > second, x becomes second (x == first is skipped, so duplicates of the max do not count).
  4. One pass, no sorting needed.
Time O(N)Space O(1)✓ 5 tests passed (Java + Python)
Trap: Sorting and taking arr[n-2] is wrong when the maximum repeats: [5, 5, 3] must give 3, not 5.
Java
import java.util.*;

public class Main {
    static long secondLargest(long[] a) {
        long first = Long.MIN_VALUE, second = Long.MIN_VALUE;
        for (long x : a) {
            if (x > first) {
                second = first;
                first = x;
            } else if (x < first && x > second) {
                second = x;
            }
        }
        return second == Long.MIN_VALUE ? -1 : second;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long[] a = new long[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextLong();
        System.out.println(secondLargest(a));
    }
}
Python
def second_largest(a):
    first = second = None
    for x in a:
        if first is None or x > first:
            second, first = first, x
        elif x < first and (second is None or x > second):
            second = x
    return -1 if second is None else second

n = int(input())
a = list(map(int, input().split()))
print(second_largest(a))

Maximum Subarray Sum (Kadane's Algorithm)

MediumArrays

Given N integers (some may be negative), print the largest sum of a contiguous subarray with at least one element.

Input: Line 1: N. Line 2: N integers.

Sample inputOutput
9
-2 1 -3 4 -1 2 1 -5 4
6
3
-5 -2 -8
-2
Approach
  1. cur = best sum of a subarray that ends at the current index; best = best seen so far.
  2. For each x: cur = max(x, cur + x) — either start fresh at x or extend the previous subarray.
  3. best = max(best, cur). Start both with the first element so an all-negative array works.
Time O(N)Space O(1)✓ 4 tests passed (Java + Python)
Trap: Starting best at 0 prints 0 for an all-negative array; the answer must be the largest single element.
Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long cur = sc.nextLong(), best = cur;
        for (int i = 1; i < n; i++) {
            long x = sc.nextLong();
            cur = Math.max(x, cur + x);
            best = Math.max(best, cur);
        }
        System.out.println(best);
    }
}
Python
n = int(input())
a = list(map(int, input().split()))
cur = best = a[0]
for x in a[1:]:
    cur = max(x, cur + x)
    best = max(best, cur)
print(best)
P3

Rotate an Array to the Right by K

MediumArrays

Rotate an array of N integers to the right by K steps (K can be larger than N) and print it.

Input: Line 1: N and K. Line 2: N integers.

Sample inputOutput
5 2
1 2 3 4 5
4 5 1 2 3
3 7
10 20 30
30 10 20
Approach
  1. Rotating N times gives the same array, so first do k = k % n.
  2. Reversal trick: reverse the whole array, then reverse the first k elements, then reverse the rest.
  3. Example [1 2 3 4 5], k=2: reverse all → 5 4 3 2 1 → reverse first 2 → 4 5 3 2 1 → reverse rest → 4 5 1 2 3.
Time O(N)Space O(1) extra✓ 4 tests passed (Java + Python)
Trap: Forgetting k % n gives an index error (or many wasted rotations) when K > N.
Java
import java.util.*;

public class Main {
    static void reverse(int[] a, int i, int j) {
        while (i < j) {
            int t = a[i]; a[i] = a[j]; a[j] = t;
            i++; j--;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(), k = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();
        k %= n;
        reverse(a, 0, n - 1);
        reverse(a, 0, k - 1);
        reverse(a, k, n - 1);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) sb.append(a[i]).append(i < n - 1 ? " " : "");
        System.out.println(sb);
    }
}
Python
n, k = map(int, input().split())
a = list(map(int, input().split()))
k %= n
a = a[-k:] + a[:-k] if k else a      # slicing does the rotation
print(*a)

P4

Valid Palindrome (Ignore Case and Symbols)

EasyStrings

A sentence is a palindrome if, after keeping only letters and digits and ignoring case, it reads the same forwards and backwards. Print YES or NO.

Input: One line of text (may contain spaces and punctuation).

Sample inputOutput
A man, a plan, a canal: Panama
YES
race a car
NO
Approach
  1. Two pointers: i from the left, j from the right.
  2. Skip characters that are not letters or digits.
  3. Compare lower-case characters; if they differ print NO. If the pointers meet, print YES.
Time O(N)Space O(1)✓ 4 tests passed (Java + Python)
Trap: Comparing without skipping spaces/punctuation, or without ignoring case, fails "A man, a plan, a canal: Panama".
Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNextLine() ? sc.nextLine() : "";
        int i = 0, j = s.length() - 1;
        boolean ok = true;
        while (i < j) {
            char a = s.charAt(i), b = s.charAt(j);
            if (!Character.isLetterOrDigit(a)) { i++; continue; }
            if (!Character.isLetterOrDigit(b)) { j--; continue; }
            if (Character.toLowerCase(a) != Character.toLowerCase(b)) { ok = false; break; }
            i++; j--;
        }
        System.out.println(ok ? "YES" : "NO");
    }
}
Python
s = input()
clean = [c.lower() for c in s if c.isalnum()]
print("YES" if clean == clean[::-1] else "NO")
P5

Check if Two Strings are Anagrams

EasyStrings

Two words are anagrams if they contain the same letters the same number of times (case-insensitive). Print YES or NO.

Input: Two lines, one word on each.

Sample inputOutput
Listen
Silent
YES
rat
car
NO
Approach
  1. If the lengths differ, the answer is NO.
  2. Count letters with an int[26] array (or a HashMap/Counter): +1 for each letter of the first word, -1 for the second.
  3. They are anagrams only if every count ends at 0.
Time O(N)Space O(1) (26 counters)✓ 4 tests passed (Java + Python)
Trap: Sorting both strings also works (O(N log N)), but remember to lower-case them first.
Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String a = sc.next().toLowerCase(), b = sc.next().toLowerCase();
        if (a.length() != b.length()) { System.out.println("NO"); return; }
        int[] cnt = new int[26];
        for (int i = 0; i < a.length(); i++) {
            cnt[a.charAt(i) - 'a']++;
            cnt[b.charAt(i) - 'a']--;
        }
        for (int c : cnt) if (c != 0) { System.out.println("NO"); return; }
        System.out.println("YES");
    }
}
Python
from collections import Counter

a = input().strip().lower()
b = input().strip().lower()
print("YES" if Counter(a) == Counter(b) else "NO")

Reverse the Words of a Sentence

EasyStrings

Reverse the order of the words in a sentence. Words are separated by one or more spaces; print them separated by a single space with no leading or trailing spaces.

Input: One line of text.

Sample inputOutput
the sky is blue
blue is sky the
  hello   world
world hello
Approach
  1. Split on whitespace: Java trim().split("\\s+"), Python split() (no argument) — both drop empty pieces.
  2. Join the words in reverse order with a single space.
Time O(N)Space O(N)✓ 3 tests passed (Java + Python)
Trap: split(" ") keeps empty strings when there are double spaces, giving extra spaces in the output.
Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String line = sc.hasNextLine() ? sc.nextLine().trim() : "";
        if (line.isEmpty()) { System.out.println(); return; }
        String[] w = line.split("\\s+");
        StringBuilder sb = new StringBuilder();
        for (int i = w.length - 1; i >= 0; i--) {
            sb.append(w[i]);
            if (i > 0) sb.append(' ');
        }
        System.out.println(sb);
    }
}

P7

String Compression (Run-Length Encoding)

MediumStrings

Compress a string by replacing each run of the same character with the character followed by the run length, e.g. aaabbc → a3b2c1.

Input: One line: a non-empty string of letters.

Sample inputOutput
aaabbc
a3b2c1
abc
a1b1c1
Approach
  1. Walk the string with index i; count how far the same character continues (index j).
  2. Append the character and the count (j - i), then jump i to j.
  3. Use a StringBuilder in Java (string + in a loop is slow, O(N²)).
Time O(N)Space O(N)✓ 4 tests passed (Java + Python)
Trap: Forgetting to output the last run after the loop ends (when using a single loop with a counter).
Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        StringBuilder sb = new StringBuilder();
        int i = 0;
        while (i < s.length()) {
            int j = i;
            while (j < s.length() && s.charAt(j) == s.charAt(i)) j++;
            sb.append(s.charAt(i)).append(j - i);
            i = j;
        }
        System.out.println(sb);
    }
}
Python
from itertools import groupby

s = input().strip()
print("".join(ch + str(len(list(run))) for ch, run in groupby(s)))
A5
O(1) lookups

Hashing

The idea
A HashMap (dict) maps a key to a value and a HashSet (set) stores unique keys. Insert, lookup and delete take O(1) on average. Turn "have I seen this before?" from an O(N) search into an O(1) check. That usually turns O(N²) into O(N).
Typical uses
Frequency counting · duplicates (set size vs list size) · Two Sum (complement lookup) · first non-repeating · group anagrams (key = sorted word) · longest consecutive sequence · subarray sum = K (map of prefix sums).
P8

First Non-Repeating Character

EasyHashing

Print the first character of the string that appears exactly once. If there is none, print -1.

Input: One line: a string of lowercase letters.

Sample inputOutput
leetcode
l
loveleetcode
v
Approach
  1. Pass 1: count every character (int[26] or HashMap).
  2. Pass 2: walk the string again in order and print the first character whose count is 1.
  3. Two passes over the string keep the original order.
Time O(N)Space O(1)✓ 4 tests passed (Java + Python)
Trap: Iterating over a HashMap instead of the string loses the original order (HashMap is unordered).
Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;
        for (char c : s.toCharArray()) {
            if (cnt[c - 'a'] == 1) { System.out.println(c); return; }
        }
        System.out.println(-1);
    }
}
Python
from collections import Counter

s = input().strip()
cnt = Counter(s)
print(next((c for c in s if cnt[c] == 1), -1))

Two Sum (Return the Indices)

EasyHashing

Given N integers and a target T, print the 0-based indices i < j of the two numbers that add up to T (exactly one answer exists).

Input: Line 1: N and T. Line 2: N integers.

Sample inputOutput
4 9
2 7 11 15
0 1
3 6
3 2 4
1 2
Approach
  1. Brute force checks every pair: O(N²).
  2. Better: a HashMap from value → index of the numbers seen so far.
  3. For each a[j], if (T - a[j]) is already in the map, the answer is (map[T - a[j]], j). Otherwise store a[j].
Time O(N)Space O(N)✓ 4 tests passed (Java + Python)
Trap: Storing all numbers first and then searching can pair an element with itself (e.g. T = 6 and a 3).
Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        long t = sc.nextLong();
        Map<Long, Integer> seen = new HashMap<>();
        for (int j = 0; j < n; j++) {
            long x = sc.nextLong();
            if (seen.containsKey(t - x)) {
                System.out.println(seen.get(t - x) + " " + j);
                return;
            }
            seen.put(x, j);
        }
    }
}
Python
n, t = map(int, input().split())
a = list(map(int, input().split()))
seen = {}
for j, x in enumerate(a):
    if t - x in seen:
        print(seen[t - x], j)
        break
    seen[x] = j
P10

Most Frequent Element (Smallest on a Tie)

MediumHashing

Print the value that appears most often. If several values share the highest frequency, print the smallest of them, followed by its frequency.

Input: Line 1: N. Line 2: N integers.

Sample inputOutput
7
4 1 2 2 4 4 1
4 3
6
5 3 5 3 9 9
3 2
Approach
  1. Count frequencies in a HashMap (Python: Counter).
  2. Pick the entry with the highest count; on equal counts prefer the smaller value.
  3. Compare with a clear rule: (count bigger) OR (count equal AND value smaller).
Time O(N)Space O(N)✓ 4 tests passed (Java + Python)
Trap: Returning the first value reached in the map on a tie — HashMap order is not sorted or insertion order.
Java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        Map<Integer, Integer> freq = new HashMap<>();
        for (int i = 0; i < n; i++) freq.merge(sc.nextInt(), 1, Integer::sum);
        int bestVal = 0, bestCnt = 0;
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            int v = e.getKey(), c = e.getValue();
            if (c > bestCnt || (c == bestCnt && v < bestVal)) {
                bestVal = v;
                bestCnt = c;
            }
        }
        System.out.println(bestVal + " " + bestCnt);
    }
}
Python
from collections import Counter

n = int(input())
cnt = Counter(map(int, input().split()))
val, c = min(cnt.items(), key=lambda kv: (-kv[1], kv[0]))
print(val, c)
A6
Two indices instead of two loops

Two Pointers & Sliding Window

Two pointers
(a) Opposite ends on a sorted array: pair sum, palindrome check, container problems. (b) Same direction (read / write pointer): remove duplicates, move zeros, partition. Each pointer moves at most N times, so the total is O(N).
Sliding window
A window [left, right] over an array or string. Grow right; when the window breaks a rule (repeat character, sum too big), shrink from left. Used for longest/shortest substring or subarray, max sum of K consecutive elements, and at most K distinct characters.

public class Main {

            count++;

        }

Final Cheat Sheet

DSA

  • Comment out throw new Exception in Java templates
  • Return (function template) vs print (full program)
  • Read the limits: 105 needs O(N log N) or better
  • Pair/complement → HashMap · sorted → two pointers
  • Substring/subarray "longest" → sliding window
  • Frequency → int[26] or Counter
  • Intervals → sort by start, then merge
  • Recursion: base case first; memoize repeats
  • Use long for sums and products
  • Test N = 1, all equal, negatives, empty
  • Exact output format, no debug prints

SQL

  • Order: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
  • Aggregate filter → HAVING, never WHERE
  • "All X even without Y" → LEFT JOIN + COUNT(y.id)
  • "No matching rows" → LEFT JOIN … WHERE y.id IS NULL
  • Manager/employee → self join with two aliases
  • Second highest → MAX(...) WHERE < (SELECT MAX…)
  • Top per group → correlated subquery with MAX
  • Duplicates → GROUP BY … HAVING COUNT(*) > 1
  • Copy aliases and column order exactly
  • DISTINCT when one row can match many

Frontend

  • Copy ids, classes and texts exactly
  • querySelector → addEventListener → change the DOM
  • classList.add / remove / toggle; className replaces all
  • textContent for text; value for inputs
  • Forms: e.preventDefault() on submit
  • Remove means el.remove()
  • Run filters/counters once on load too
  • React: useState + setter, className, key in map
  • Vue: v-model, v-for + :key, v-if, computed, :class
  • No red errors in the Console
