How the real round works

  • The exam usually gives 1 SQL question. You write one query in the editor.
  • Run Query runs your query on sample data and shows the output.
  • Check Query runs it against 5 test cases. Test case 1 uses the sample data, while 2–5 use hidden data with edge cases (ties, NULLs, exact boundary values, repeated rows).
  • Your column names must match the required aliases, and the rows must match exactly.
  • When the timer ends, your last query is checked automatically.
