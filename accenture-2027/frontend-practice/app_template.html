How the real round works

  • You get 1 front-end question. The Question tab lists the objectives and constraints; the HTML, CSS and JavaScript tabs hold the starter code with TODOs.
  • The Result pane updates as you type. Console shows console.log output and errors.
  • Your code is graded by hidden test cases that check the DOM, the computed CSS and the behaviour (clicks, typing). Follow ids, classes and texts exactly.
  • Here, Run Tests shows which objectives already pass. When the timer ends, your code is submitted automatically.
