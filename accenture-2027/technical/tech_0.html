⏱ 1 minute per question

45 questions in 45 minutes. Recall-based questions (Parts A, C and D) should take about 30–40 seconds, which saves time for pseudocode.

🧠 No pen and paper

Practise tracing code in your head. Track only the variables that change, and work out the first 2–3 loop passes to spot the pattern.

🚫 Most eliminations

Candidates report this as the toughest filter. Parts C and D are pure memory, so revise them well: they're the easiest marks to secure.
