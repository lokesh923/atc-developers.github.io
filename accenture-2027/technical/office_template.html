Data Entry, Formulas & Precedence

Numbers vs text
Numbers align right by default and text aligns left. Typing '123 (with an apostrophe) stores 123 as text.
Dates are numbers
Excel stores a date as a serial number: 1 = 1-Jan-1900. So you can subtract dates to get days: ="15-Mar-2024"-"1-Mar-2024" = 14.
Booleans
TRUE and FALSE behave as 1 and 0 in arithmetic: =TRUE+TRUE = 2.
AutoFill & Flash Fill. Drag the fill handle to copy or continue a pattern (Mon → Tue → Wed, 1, 3, 5…). Flash Fill (Ctrl+E) learns a pattern from one or two examples you type, such as extracting first names, and fills the rest.

Formula rules

  • Every formula starts with =. Functions use the pattern =NAME(arguments), with arguments separated by commas.
  • Reference operators: : range (A1:A5) · , union (SUM(A1,C1)) · space intersection (=B1:B5 A3:D3 gives B3).
  • Text goes in double quotes: "HR". To join text use &: =A2&" "&B2.
  • Refer to another sheet with =Sheet2!A1, or ='Sales Data'!B4 if the name has spaces.

Cell References

When you copy a formula, Excel shifts its references by the same number of rows and columns you moved it. The $ sign locks the part that comes right after it.

TypeWrittenColumnRowCopy from C2 → E5 (2 columns right, 3 rows down)
RelativeA1movesmoves=A1 → =C4
Absolute$A$1lockedlocked=$A$1 → =$A$1
Mixed$A1lockedmoves=$A1 → =$A4
MixedA$1moveslocked=A$1 → =C$1
The 2-step method for copy questions
  1. Count how far the formula moved: columns right or left, rows down or up.
  2. Shift every part without a $ by that amount. Leave every part with a $ unchanged.
Example: =$B2*C$1 copied from D2 to F4 (+2 columns, +2 rows) → =$B4*E$1.
Why it matters: a percentage table With total sales in $B$10, type =B2/$B$10 in C2 and drag down to C9. Each row divides by the same fixed total.
F4 cycles: A1 → $A$1 → A$1 → $A1 → A1.
Named ranges (Formulas → Name Manager, or type into the Name Box): call C2:C7 "Salary", then write =SUM(Salary). Names are always absolute. Tables (Ctrl+T) use structured references like =SUM(Table1[Salary]) and grow automatically when you add rows.
Trap: moving a formula (cut and paste) does not change its references. Only copying shifts them. Deleting a referenced row turns the reference into #REF!.

Logical & Conditional Functions

IF(logical_test, value_if_true, value_if_false)
=IF(C3>50000,"High","Low") → High · =IF(D5>=2,"Eligible","") → "" (empty text)
Nested: =IF(C4>=60000,"A",IF(C4>=45000,"B","C")) → A. Test from the highest condition down.
IFS (2019+): =IFS(C4>=60000,"A",C4>=45000,"B",TRUE,"C"), with no nesting needed.
AND(…)
TRUE only if all are TRUE
=AND(B3="IT",D3>=5) → TRUE
OR(…)
TRUE if any is TRUE
=OR(B5="HR",D5>3) → FALSE
NOT(…)
Reverses TRUE/FALSE
=NOT(B2="HR") → FALSE
IFERROR(value, value_if_error): =IFERROR(C2/0,"NA") → NA. IFNA catches only #N/A.

Find and fetch

Lookup Functions

VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
  1. It searches for lookup_value in the first column of table_array.
  2. It goes across that row to column number col_index_num, counted within the table starting from 1.
  3. FALSE/0 = exact match (use this almost always). TRUE/omitted = approximate match, which returns the largest value ≤ the lookup value and needs the first column sorted ascending.
=VLOOKUP("Priya",A2:D7,2,FALSE) → HR  ·  =VLOOKUP("Priya",A2:D7,3,FALSE) → 45000  ·  =VLOOKUP(78,F2:G6,2,TRUE) → B
VLOOKUP limits: (1) It only looks to the right. (2) col_index_num = 0 gives #VALUE!, and a number bigger than the table width gives #REF!. (3) A value that isn't found gives #N/A. (4) It returns only the first match. (5) Leaving out FALSE on unsorted data can give wrong answers silently.
HLOOKUP
The horizontal version: it searches the first row and returns from row number n.
=HLOOKUP("Exp",A1:D7,3,FALSE) → 5
MATCH(value, range, [type])
Returns the position of the value. 0 = exact, 1 = largest ≤ (ascending), −1 = smallest ≥ (descending).
=MATCH("John",A2:A7,0) → 4
INDEX(range, row, [col])
Returns the value at a position.
=INDEX(A2:D7,3,1) → Meena
INDEX + MATCH (it can look left)
=INDEX(A2:A7,MATCH(51000,C2:C7,0)) → Arjun
XLOOKUP (Excel 365/2021)
=XLOOKUP("Ravi",A2:A7,C2:C7,"Not found") → 55000. Exact by default, looks in any direction, and has a built-in "not found" value.
CHOOSE(index, v1, v2, …)
=CHOOSE(2,"Red","Green","Blue") → Green

Work with data

Data Tools, Pivots, Charts & Printing

Sort reorders rows: A→Z, Z→A, by colour, or by several levels (for example Dept, then Salary). Always select the whole table so rows stay together.
Filter (Ctrl+Shift+L) hides rows that don't match. Nothing is deleted. Advanced Filter can copy matching rows somewhere else.
Remove Duplicates deletes repeated rows, based on the columns you choose.
Text to Columns splits one column into several using a delimiter (comma or space) or a fixed width. Example: "Ravi Kumar" → "Ravi" | "Kumar".
Data Validation limits what can be typed: a list (drop-down), whole number between 1 and 100, dates, text length. It can show an input message and an error alert.
Conditional Formatting changes a cell's look based on its value: highlight rules (> 50000), top/bottom 10, data bars, colour scales, icon sets, duplicates.
Freeze Panes keeps headers visible while scrolling. Split divides the window into separately scrollable panes.
Group / Subtotal collapses detail rows (outline), and Subtotal inserts totals for each group of sorted data.

What-If Analysis

Goal Seek
"What input gives this result?" For example, which loan amount gives an EMI of ₹10,000. One variable.
Scenario Manager
Saves and compares sets of inputs: best case, worst case and expected case.
Data Table
Shows results for many input values at once (one or two variables). Solver (an add-in) optimises with constraints.

Formatting, Styles & Page Layout

Character formatting
Font, size, bold (Ctrl+B), italic (Ctrl+I), underline (Ctrl+U), strikethrough, subscript (Ctrl+=), superscript (Ctrl+Shift+=), highlight, font colour, change case (Shift+F3), clear formatting.
Paragraph formatting
Alignment: left (Ctrl+L), centre (Ctrl+E), right (Ctrl+R), justify (Ctrl+J). Line spacing: 1.0 (Ctrl+1), 1.5 (Ctrl+5), 2.0 (Ctrl+2). Indents: first-line, hanging, left and right. Spacing before and after, borders, shading.
Styles & themes
A style is a saved set of formatting (Normal, Heading 1…). Change the style once and every paragraph using it updates. Heading styles drive the Navigation Pane and the TOC.
Format Painter
Copies formatting from one piece of text to another. A single click applies it once, a double click keeps it on until Esc. Ctrl+Shift+C / Ctrl+Shift+V copy and paste formatting.
BreakWhat it does

Column breakThe following text moves to the next column (in a multi-column layout)
Text wrapping / line break (Shift+Enter)A new line in the same paragraph
Section break: Next Page, Continuous, Even, OddStarts a new section that can have its own orientation, margins, headers, footers, page numbering and columns. Example: one landscape page in a portrait document.
Header / Footer
Repeats on every page: titles and page numbers. Options include "Different first page" and "Different odd and even".
Columns & Drop Cap
Newspaper-style columns (Layout tab). A drop cap is a large first letter (Insert tab).
Watermark
Faint text or an image behind the content, like "CONFIDENTIAL" or "DRAFT" (Design tab).

Long documents

Tables, References & Mail Merge

Tables
Insert → Table. You can merge and split cells, repeat the header row, and sort. Insert → Table → Convert Text to Table uses a separator such as a tab or comma. Formulas: Layout → Formula → =SUM(ABOVE) (also LEFT, RIGHT, BELOW).
Table of Contents
Built automatically from Heading styles (References tab). Use Update Table after editing.
Footnote vs Endnote
A footnote appears at the bottom of the same page (Alt+Ctrl+F). An endnote appears at the end of the document or section (Alt+Ctrl+D).
Captions, Citations, Index
Captions number figures and tables ("Figure 1"). Citations plus a bibliography handle references in APA, MLA and other styles. An index lists marked terms with page numbers.
Mail Merge: one template, many personalised documents
  1. Start Mail Merge: choose letters, emails, envelopes, labels or a directory.
  2. Select Recipients: type a list, use an Excel sheet, or use Outlook contacts.
  3. Insert Merge Fields like «Name» and «City» into the main document.
  4. Preview Results, then Finish & Merge: edit, print or send emails.
The main document holds the fixed text, and the data source holds the varying data.

Excel in 12 lines

  • $ locks what follows it · copying shifts, cutting doesn't · F4 toggles
  • Precedence: − (negation) → % → ^ → * / → + − → & → comparisons · =-3^2 = 9
  • COUNT = numbers · COUNTA = non-empty · COUNTBLANK = empty
  • SUMIF(range, criteria, sum_range) but SUMIFS(sum_range, range, criteria…)
  • Criteria: ">50", "<>HR", "A*", "?b", ">"&F1
  • VLOOKUP: first column, looks right, FALSE = exact · approximate needs sorted data
  • INDEX + MATCH can look left · MATCH type 0 = exact
  • INT rounds down · TRUNC chops · ROUND halves away from zero · MOD takes the divisor's sign
  • FIND case-sensitive · SEARCH not case-sensitive + wildcards · SUBSTITUTE by text · REPLACE by position
  • Errors: DIV/0 · N/A (not found) · VALUE (type) · REF (deleted) · NAME (typo) · NUM · NULL · #### (narrow)
  • Validation = restrict input · Conditional formatting = change look · Freeze = keep headers · Goal Seek = find input
  • 1,048,576 rows · 16,384 columns (XFD) · .xlsm = macros · .csv = one sheet of plain text

Word · PowerPoint · Apps in 12 lines

  • Section break = different orientation, header or margins for part of a document
  • Ctrl+Enter page break · Shift+Enter line break
  • TOC is built from heading styles · footnote = same page · endnote = end of document
  • Mail Merge (Mailings): main document + data source → personalised copies
  • Track Changes (Review) → accept or reject · F7 spelling · Shift+F3 change case
  • Watermark is on the Design tab · Format Painter copies formatting
  • Slide Master = every slide · layouts = each type of slide
  • Animation = objects (entrance, emphasis, exit, path) · Transition = between slides
  • F5 from start · Shift+F5 from current · B black · W white · Esc end
  • Slide Sorter = reorder · .ppsx opens as a show · Rehearse Timings
  • BCC is hidden · Reply All doesn't include BCC · Ctrl+Shift+Esc opens Task Manager
  • Win+L lock · Win+D desktop · Win+Shift+S snip · Win+V clipboard
Exam-day tipFor a formula-output question, work out the answer yourself before looking at the options. Wrong options are built from common mistakes, such as including the boundary value, using the wrong rounding direction or picking the wrong column. Then check that your answer is among the options.
