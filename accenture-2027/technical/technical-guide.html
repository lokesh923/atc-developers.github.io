Excel foundations

References, Formulas & Order of Operations

Formula basics. Every formula starts with =. A cell is named by column letter + row number (B3). A range uses a colon (A1:C5), and separate cells use commas (SUM(A1,C1)).

Cell references: the most-tested Excel concept

TypeLooks likeWhen copied to another cell…Example: copy from C1 to D2
RelativeA1Row and column both shift=A1 → =B2
Absolute$A$1Nothing shifts (it's locked)=$A$1 → =$A$1
Mixed (column locked)$A1Only the row shifts=$A1 → =$A2
Mixed (row locked)A$1Only the column shifts=A$1 → =B$1

Press F4 while editing a reference to cycle through A1 → $A$1 → A$1 → $A1. Rule: the $ sign "pins" whatever comes right after it.

Order of operations in Excel

Lookup functions

VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
Searches the first column of the table and returns the value from column number col_index_num of the same row.
FALSE (or 0) = exact match. TRUE (or omitted) = approximate match, which needs the first column sorted ascending.
=VLOOKUP("Ravi",A2:C6,2,FALSE) → IT   ·   =VLOOKUP("Ravi",A2:C6,3,FALSE) → 55000
HLOOKUP
Same as VLOOKUP, but searches the first row and returns from row number n.
INDEX + MATCH
=INDEX(C2:C6,MATCH("John",A2:A6,0)) → 38000. It can look left, which VLOOKUP cannot.
XLOOKUP (newer Excel)
=XLOOKUP("John",A2:A6,C2:C6) → 38000. Exact match by default.
VLOOKUP traps: (1) It only looks to the right of the first column. (2) A col_index_num larger than the table width gives #REF!. (3) A value that isn't found gives #N/A. (4) If you forget FALSE, it does an approximate match, which can return wrong results on unsorted data.

Word, PowerPoint & Shortcuts

MS Word essentials

  • Styles (Heading 1, 2…) give a consistent format and power the automatic Table of Contents (References tab).
  • Page break starts a new page. A section break lets a part of the document have different headers, footers, orientation or margins.
  • Header/Footer repeat on every page, for page numbers and titles.
  • Mail Merge creates bulk personalised letters, labels or emails from a data list (Mailings tab).
  • Track Changes and Comments are used for reviewing (Review tab).
  • Find & Replace (Ctrl+H) and Format Painter (copies formatting).
  • Line spacing, indents and alignment: left, centre, right, justify.

PowerPoint essentials

  • Slide Master controls the theme, fonts, logo and layouts of all slides.
  • Animation moves objects on a slide. Transition is the effect between slides.
  • Views: Normal (editing), Slide Sorter (rearranging slides), Reading, Notes Page and Presenter View (speaker notes plus the next slide).
  • Speaker notes are visible only to the presenter.
  • Hide Slide keeps a slide in the file but skips it during the show.
  • File types: .pptx (presentation), .ppsx (opens straight into the slideshow), .potx (template).

Reading Pseudocode & Operators

Pseudocode is language-neutral, but it behaves like C or Java. These are the conventions you'll see:

// declarations
Integer a = 5, b
Set b = a + 2          // assignment
if (a > b) ... else ... end if
for (i = 1 to 5) ... end for  // 1..5 inclusive
while (cond) ... end while
Function f(Integer n) ... return x
Print a, b
OperatorMeaning
/ on integersInteger division: 7/2 = 3
mod or %Remainder: 17 mod 5 = 2
&& || !Logical AND, OR, NOT
& | ^ ~Bitwise AND, OR, XOR, NOT
<< >>Left / right shift
== vs =Comparison vs assignment

Operator precedence (C/Java style, highest first)

LevelOperatorsExample
1() []—
2Unary ! ~ ++ -- -~5 = -6
3* / %2 + 3 * 4 = 14
4+ -10 - 4 - 3 = 3 (left to right)
5<< >>1 << 2 + 1 = 1 << 3 = 8
6< <= > >= then == !=—
7& then ^ then |5 | 2 & 3 = 5 | 2 = 7
8&& then ||—
9?:, then assignment = += -=—
Two classic traps: (1) + binds tighter than <<, so 1 << 2 + 1 is 8, not 5. (2) == binds tighter than &, so x & 1 == 0 means x & (1 == 0). When unsure, assume the question wants the precedence rules applied literally.
Increment operators. x++ uses the value first, then adds 1. ++x adds 1 first. With a = 5: b = a++ gives b = 5, a = 6, and b = ++a gives b = 6, a = 6.

Shortcuts that save minutes

Shifts
x << n = x × 2ⁿ
x >> n = x ÷ 2ⁿ (integer)
NOT
~x = −(x + 1)
~0 = −1, ~(−1) = 0
XOR rules
x ^ x = 0 · x ^ 0 = x
Three XORs swap two variables
Odd or even
x & 1 = 1 if odd, 0 if even
Power of 2?
x & (x − 1) == 0 for 1, 2, 4, 8…
Identity
a + b = (a ^ b) + 2·(a & b)
(a | b) = (a ^ b) + (a & b)
Remember: x & (x − 1) clears the lowest set bit. A loop that does this until x becomes 0 counts the 1-bits. So does a loop of c += x & 1; x >>= 1.

Loop-count formulas

LoopIterations

Recursion: unwind it on the way down, add it up on the way back

Function f(Integer n)
    if (n == 0) return 0
    return n mod 10 + f(n / 10)
Print f(472)
Trace (digit sum)
f(472) = 2 + f(47)
f(47) = 7 + f(4)
f(4) = 4 + f(0) = 4 + 0
Back up: 4 → 11 → 13
Factorial
f(n) = n × f(n−1), f(0) = 1 → f(5) = 120
Fibonacci
f(n) = f(n−1) + f(n−2) → 0 1 1 2 3 5 8 13…
GCD (Euclid)
g(a, b) = g(b, a mod b), g(a, 0) = a
Print order trap: if a function prints before its recursive call, the output comes in forward order. If it prints after the call, the output comes in reverse order. For example, printing n after f(n−1) with n = 3 gives "1 2 3".

Arrays & strings

  • Indexes usually start at 0: an array of 5 elements runs from index 0 to 4. Going past the end is an out-of-bounds error.
  • Common patterns: running max/min, swapping a[i] and a[n−1−i] to reverse, counting characters, checking palindromes.
  • For a string s, length(s) gives the number of characters. s[i] is the i-th character, and 'A' has ASCII code 65 ('a' = 97, '0' = 48).

Object-oriented programming

OOPs: The Four Pillars & Beyond

Class vs Object. A class is a blueprint (for example, Car). An object is a real instance created from it (Car c = new Car()). The class defines attributes (data) and methods (behaviour).
PillarMeaningExample
EncapsulationBundles data and methods together and hides internal stateprivate int balance; accessed only through getBalance() / deposit()
AbstractionShows what something does and hides howabstract class Shape { abstract double area(); }, or interfaces
InheritanceA child class reuses a parent's members (an "is-a" relationship)class Dog extends Animal
PolymorphismOne name, many formsOverloading (compile time) and overriding (run time)
Overloading (compile time)
Same method name in the same class, with different parameters.
add(int a, int b) and add(double a, double b)
Overriding (run time)
A child redefines a parent method with the same signature. Which version runs depends on the actual object: Animal a = new Dog(); a.sound(); runs Dog's sound().

Constructor
Same name as the class, no return type, runs automatically when an object is created. It can be overloaded.
Abstract class vs Interface
An abstract class can have state and concrete methods. A class can extend one abstract class but implement many interfaces.
static / this / super
static belongs to the class, not to objects. this is the current object. super refers to the parent's members or constructor.

Hub vs Switch vs Router
A hub sends to all ports (L1). A switch sends to the right device using the MAC address (L2). A router connects different networks using IP (L3).
MAC vs IP
A MAC address is a 48-bit physical address burnt into the NIC. An IP address is a logical address that can change. ARP finds the MAC for an IP.

HTTP

  • HTTP sends plain text on port 80. HTTPS = HTTP + TLS encryption on port 443 (the padlock icon).
  • Methods: GET (read), POST (create), PUT (replace), PATCH (modify), DELETE.
  • Status codes: 1xx info · 2xx success (200 OK, 201 Created) · 3xx redirect (301 moved permanently) · 4xx client error (400 bad request, 401 unauthorised, 403 forbidden, 404 not found) · 5xx server error (500 internal error, 503 unavailable).
  • HTTP is stateless. Cookies and sessions remember users between requests.

DNS & DHCP

  • DNS translates names to IP addresses (www.example.com → 93.184.x.x). It checks the browser cache, then the OS, then a recursive resolver, then the root, TLD and authoritative servers.
  • DNS records: A (IPv4), AAAA (IPv6), CNAME (alias), MX (mail server), NS (name server), TXT.
  • DHCP automatically gives a device its IP address, subnet mask, gateway and DNS using DORA: Discover → Offer → Request → Acknowledge.
  • ICMP is used by ping and traceroute. NAT maps private IPs to one public IP.

Single loop to nO(n)
Loop to n containing a halving loop; merge sortO(n log n)
Two nested loops to nO(n²)
Naive recursive Fibonacci; all subsetsO(2ⁿ)

Rules: drop constants (O(2n) = O(n)), keep only the dominant term (O(n² + n) = O(n²)). Sequential blocks add, and nested blocks multiply. Growth order: 1 < log n < n < n log n < n² < 2ⁿ < n!

D4
Store data

DBMS Basics

DBMS vs RDBMS
An RDBMS stores data in related tables (rows = records/tuples, columns = attributes) and uses SQL. Examples: MySQL, Oracle, PostgreSQL, SQL Server. NoSQL examples: MongoDB, Cassandra.
ACID (transactions)
Atomicity: all or nothing. Consistency: valid state to valid state. Isolation: concurrent transactions don't interfere. Durability: committed data survives crashes.
KeyDefinition
Super keyAny set of columns that uniquely identifies a row
Candidate keyA minimal super key (no extra columns)
Primary keyThe chosen candidate key: unique + NOT NULL, one per table
Alternate keyCandidate keys not chosen as primary
Foreign keyA column referencing another table's primary key (referential integrity)
Composite keyA key made of 2 or more columns
Unique keyValues must be unique but can be NULL (one NULL in most databases)
Normal formRule
1NFAtomic (single) values, no repeating groups
2NF1NF + no partial dependency on part of a composite key
3NF2NF + no transitive dependency (non-key → non-key)
BCNFEvery determinant is a candidate key
SQL familyCommands
DDL (structure)CREATE, ALTER, DROP, TRUNCATE, RENAME
DML (data)INSERT, UPDATE, DELETE
DQL (query)SELECT
DCL (access)GRANT, REVOKE
TCL (transactions)COMMIT, ROLLBACK, SAVEPOINT
DELETE
DML. Removes rows (can use WHERE). Can be rolled back. Slower.
TRUNCATE
DDL. Removes all rows quickly but keeps the table structure.
DROP
DDL. Removes the whole table: structure and data.
Query order and joins. Written order: SELECT … FROM … WHERE … GROUP BY … HAVING … ORDER BY. WHERE filters rows before grouping, and HAVING filters groups. INNER JOIN returns only matching rows. LEFT JOIN returns all left rows (NULL where there's no match), and RIGHT JOIN returns all right rows. An ER diagram shows entities (rectangles), attributes (ovals) and relationships (diamonds) with cardinality 1:1, 1:N or M:N.
