Reading Pseudocode & Operators

Pseudocode is language-neutral, but it behaves like C or Java. These are the conventions you'll see:

// declarations
Integer a = 5, b
Set b = a + 2          // assignment
if (a > b) ... else ... end if
for (i = 1 to 5) ... end for  // 1..5 inclusive
while (cond) ... end while
Function f(Integer n) ... return x
Print a, b

Two classic traps: (1) + binds tighter than <<, so 1 << 2 + 1 is 8, not 5. (2) == binds tighter than &, so x & 1 == 0 means x & (1 == 0). When unsure, assume the question wants the precedence rules applied literally.
Increment operators. x++ uses the value first, then adds 1. ++x adds 1 first. With a = 5: b = a++ gives b = 5, a = 6, and b = ++a gives b = 6, a = 6.

Shortcuts that save minutes

Shifts
x << n = x × 2ⁿ
x >> n = x ÷ 2ⁿ (integer)
NOT
~x = −(x + 1)
~0 = −1, ~(−1) = 0
XOR rules
x ^ x = 0 · x ^ 0 = x
Three XORs swap two variables
Odd or even
x & 1 = 1 if odd, 0 if even
Power of 2?
x & (x − 1) == 0 for 1, 2, 4, 8…
Identity
a + b = (a ^ b) + 2·(a & b)
(a | b) = (a ^ b) + (a & b)
Remember: x & (x − 1) clears the lowest set bit. A loop that does this until x becomes 0 counts the 1-bits. So does a loop of c += x & 1; x >>= 1.

Recursion: unwind it on the way down, add it up on the way back

Function f(Integer n)
    if (n == 0) return 0
    return n mod 10 + f(n / 10)
Print f(472)
Trace (digit sum)
f(472) = 2 + f(47)
f(47) = 7 + f(4)
f(4) = 4 + f(0) = 4 + 0
Back up: 4 → 11 → 13
Factorial
f(n) = n × f(n−1), f(0) = 1 → f(5) = 120
Fibonacci
f(n) = f(n−1) + f(n−2) → 0 1 1 2 3 5 8 13…
GCD (Euclid)
g(a, b) = g(b, a mod b), g(a, 0) = a
Print order trap: if a function prints before its recursive call, the output comes in forward order. If it prints after the call, the output comes in reverse order. For example, printing n after f(n−1) with n = 3 gives "1 2 3".

Arrays & strings

  • Indexes usually start at 0: an array of 5 elements runs from index 0 to 4. Going past the end is an out-of-bounds error.
  • Common patterns: running max/min, swapping a[i] and a[n−1−i] to reverse, counting characters, checking palindromes.
  • For a string s, length(s) gives the number of characters. s[i] is the i-th character, and 'A' has ASCII code 65 ('a' = 97, '0' = 48).

Object-oriented programming

OOPs: The Four Pillars & Beyond

Class vs Object. A class is a blueprint (for example, Car). An object is a real instance created from it (Car c = new Car()). The class defines attributes (data) and methods (behaviour).
PillarMeaningExample
EncapsulationBundles data and methods together and hides internal stateprivate int balance; accessed only through getBalance() / deposit()
AbstractionShows what something does and hides howabstract class Shape { abstract double area(); }, or interfaces
InheritanceA child class reuses a parent's members (an "is-a" relationship)class Dog extends Animal
PolymorphismOne name, many formsOverloading (compile time) and overriding (run time)
Overloading (compile time)
Same method name in the same class, with different parameters.
add(int a, int b) and add(double a, double b)
Overriding (run time)
A child redefines a parent method with the same signature. Which version runs depends on the actual object: Animal a = new Dog(); a.sound(); runs Dog's sound().

Constructor
Same name as the class, no return type, runs automatically when an object is created. It can be overloaded.
Abstract class vs Interface
An abstract class can have state and concrete methods. A class can extend one abstract class but implement many interfaces.
static / this / super
static belongs to the class, not to objects. this is the current object. super refers to the parent's members or constructor.
Also know: final class = can't be inherited · final method = can't be overridden · association (uses-a), aggregation (has-a, parts can exist alone) and composition (has-a, parts die with the whole).
