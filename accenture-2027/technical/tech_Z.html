One-page cheat sheet

A · Office

  • $A$1 fixed · $A1 column fixed · A$1 row fixed · F4 toggles
  • VLOOKUP: first column, look right, FALSE = exact, not found = #N/A
  • COUNT = numbers · COUNTA = non-empty · COUNTIF(range, criteria) · SUMIF(range, criteria, sum_range)
  • #DIV/0! · #N/A · #VALUE! · #REF! · #NAME? · #### (narrow column)
  • Slide Master = all slides · Animation = objects · Transition = between slides

B · Pseudocode + OOPs

  • x<<n = x·2ⁿ · x>>n = x/2ⁿ · ~x = −(x+1) · x^x = 0
  • + before << · == before & · integer / truncates
  • Nested loops j = i to n run n(n+1)/2 times · i *= 2 runs log n times
  • Recursion: expand down, add up on the way back. Printing after the call gives reverse order.
  • Overloading = same class, different parameters · Overriding = child redefines, decided at run time

C · Networking · Security · Cloud

  • L3 router/IP · L2 switch/MAC · L1 hub · L4 TCP/UDP
  • 22 SSH · 25 SMTP · 53 DNS · 67/68 DHCP · 80 HTTP · 443 HTTPS
  • Private: 10/8 · 172.16–31 · 192.168/16 · hosts = 2ʰ − 2
  • AES symmetric · RSA asymmetric · SHA hashing (one-way)
  • IaaS = EC2 · PaaS = App Engine · SaaS = Gmail · Hybrid = private + public

D · CS Fundamentals

  • Stack LIFO (DFS, undo) · Queue FIFO (BFS, scheduling)
  • Binary search needs sorted data, O(log n) · Merge sort is always O(n log n) · Quick sort worst O(n²)
  • Stable sorts: bubble, insertion, merge · Not stable: selection, quick, heap
  • PK = unique + not null · FK → another table's PK · 2NF partial · 3NF transitive
  • DDL: CREATE/ALTER/DROP/TRUNCATE · DML: INSERT/UPDATE/DELETE · ACID
Final wordParts A, C and D reward revision, and Part B rewards practice. Lock in the easy recall marks first, then win the pseudocode section by tracing calmly: write nothing down, track only what changes, and spot the pattern.
