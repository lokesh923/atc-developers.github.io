Hub vs Switch vs Router
A hub sends to all ports (L1). A switch sends to the right device using the MAC address (L2). A router connects different networks using IP (L3).
MAC vs IP
A MAC address is a 48-bit physical address burnt into the NIC. An IP address is a logical address that can change. ARP finds the MAC for an IP.
LAN / MAN / WAN
Building → city → country or world. The Internet is the largest WAN. Topologies: bus, star (most common), ring, mesh, tree.

HTTP

  • HTTP sends plain text on port 80. HTTPS = HTTP + TLS encryption on port 443 (the padlock icon).
  • Methods: GET (read), POST (create), PUT (replace), PATCH (modify), DELETE.
  • Status codes: 1xx info · 2xx success (200 OK, 201 Created) · 3xx redirect (301 moved permanently) · 4xx client error (400 bad request, 401 unauthorised, 403 forbidden, 404 not found) · 5xx server error (500 internal error, 503 unavailable).
  • HTTP is stateless. Cookies and sessions remember users between requests.

DNS & DHCP

  • DNS translates names to IP addresses (www.example.com → 93.184.x.x). It checks the browser cache, then the OS, then a recursive resolver, then the root, TLD and authoritative servers.
  • DNS records: A (IPv4), AAAA (IPv6), CNAME (alias), MX (mail server), NS (name server), TXT.
  • DHCP automatically gives a device its IP address, subnet mask, gateway and DNS using DORA: Discover → Offer → Request → Acknowledge.
  • ICMP is used by ping and traceroute. NAT maps private IPs to one public IP.

Protect the system

Security: Encryption, Malware, Attacks

CIA triad
Confidentiality: only authorised people can see the data.
Integrity: the data isn't altered.
Availability: the system is accessible when needed.
AuthN vs AuthZ
Authentication answers "who are you?" (password, OTP, biometrics). Authorization answers "what are you allowed to do?" (permissions). MFA combines 2 or more factors.
Firewall & VPN
A firewall filters traffic by rules (packet-filtering, stateful, application/WAF). A VPN creates an encrypted tunnel over the internet. A proxy forwards requests on your behalf.
TechniqueHow it worksExamples
Symmetric encryptionThe same key encrypts and decrypts. It's fast, but the key must be shared securely.AES, DES, 3DES
Asymmetric encryptionA public key encrypts and the private key decrypts. It solves key sharing but is slower.RSA, ECC, Diffie–Hellman (key exchange)
HashingA one-way fixed-length fingerprint that can't be reversed. Used to store passwords and check integrity.SHA-256, (MD5: weak)
Digital signatureThe sender hashes the data and signs it with their private key. Anyone can verify it with the public key. It proves authenticity and integrity.TLS certificates

Virtualisation
A hypervisor runs several VMs on one physical server.
VM vs Container
A VM includes a full guest OS (heavy). A container shares the host kernel (light and fast to start).
Scaling
Vertical = a bigger machine. Horizontal = more machines. Elasticity = scaling automatically with demand.

DevOps, CI/CD, Git & Docker

DevOps brings development and operations together to deliver faster and more reliably. Pipeline: Plan → Code → Build → Test → Release → Deploy → Operate → Monitor. CI (Continuous Integration) means merging code often and automatically building and testing each change. CD means Continuous Delivery (always ready to release) or Continuous Deployment (released automatically). Tools: Jenkins, GitHub Actions, GitLab CI.
