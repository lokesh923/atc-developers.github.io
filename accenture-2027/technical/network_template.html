The basics

Network Basics, Types & Topologies

Network: two or more devices (nodes) connected to share data and resources. A protocol is an agreed set of rules for communication. Bandwidth = maximum data rate (bps). Throughput = the rate actually achieved. Latency = delay (ms). 1 Byte = 8 bits, so 100 Mbps ≈ 12.5 MB/s.

Transmission media
Twisted pair (Cat5e/Cat6, RJ-45, most LANs) · Coaxial (cable TV) · Fibre optic (light, fastest, long distance, immune to interference. Single-mode = long distance, multi-mode = short) · Wireless (radio, microwave, infrared).
Architectures
Client–server: central servers provide services (web, mail). Peer-to-peer: every node is both client and server (BitTorrent).
Switching methods
Circuit switching: a dedicated path for the whole session (old telephone network). Packet switching: data is split into packets that may take different routes (the internet).

Addresses

IP Addressing, Subnetting & IPv6

IPv4 = 32 bits written as 4 octets in dotted decimal (each 0–255), for example 192.168.1.10. Every address has a network part and a host part, split by the subnet mask (255.255.255.0, or /24 in CIDR notation, meaning 24 network bits).

Subnetting in 3 formulas
  1. Host bits h = 32 − prefix → usable hosts = 2ʰ − 2 (minus the network and broadcast addresses).
  2. Block size = 256 − (the mask's last non-255 octet) = 2ʰ in the last octet. Subnets start at multiples of the block size.
  3. For any host: network = the block start at or below the host · broadcast = next block start − 1 · usable hosts = network + 1 up to broadcast − 1.
Worked example: 192.168.10.77/26. h = 6 → 62 hosts. The mask is 255.255.255.192, so the block is 64 and the blocks are .0, .64, .128, .192. 77 is in the .64 block: network 192.168.10.64, broadcast .127, hosts .65–.126.

IPv6
128 bits, written as 8 groups of 4 hex digits: 2001:0db8:0000:0000:0000:0000:0000:0001 → 2001:db8::1. Leading zeros can be dropped, and :: can be used once. There's no broadcast (it uses multicast and anycast instead). Loopback is ::1.
NAT / PAT
NAT translates private IPs to a public IP at the router. PAT (NAT overload) lets many devices share one public IP by using different ports. It's why home networks work with one ISP address.
MAC address
48-bit physical (hardware) address, like 00:1A:2B:3C:4D:5E. The first 24 bits are the OUI (manufacturer). ARP maps IP → MAC, and the old RARP maps MAC → IP.
Public vs private IP · static vs dynamic: a public IP is globally unique and routable on the internet. A private IP is reusable inside LANs and isn't routed on the internet. A static IP is fixed (servers). A dynamic IP is assigned by DHCP (laptops, phones). Supernetting or CIDR aggregation combines networks, such as two /24s into one /23.

DNS: how www.example.com is resolved
  1. Check the browser cache, then the OS cache and hosts file.
  2. Ask the recursive resolver (usually the ISP's, or 8.8.8.8).
  3. The resolver asks a root server, which sends it to the .com TLD server, which sends it to the authoritative server for example.com.
  4. The IP is returned and cached for the record's TTL.
Records: A (IPv4) · AAAA (IPv6) · CNAME (alias) · MX (mail) · NS (name server) · PTR (reverse lookup) · TXT (verification).
DHCP: DORA
  1. Discover: the client broadcasts "any DHCP server out there?"
  2. Offer: the server offers an IP address.
  3. Request: the client requests that offer.
  4. Acknowledge: the server confirms. The client gets an IP, mask, gateway and DNS for a lease period.
ICMP carries ping (echo request/reply) and traceroute (TTL expiry). Useful commands: ipconfig/ifconfig, ping, tracert/traceroute, nslookup, netstat.
N7
Getting packets around

Routing, Switching & Wi-Fi

Routing
Static routes are set manually (simple and predictable). Dynamic routes are learned automatically:
• RIP: distance-vector, metric = hop count, max 15 (16 = unreachable)
• OSPF: link-state, shortest path (Dijkstra), used inside organisations
• BGP: path-vector, routes between autonomous systems. It's the protocol of the internet.
The default gateway is where packets go when no specific route matches.
Switching concepts
A MAC table maps port ↔ MAC. A VLAN logically splits one switch into separate broadcast domains (for example HR and IT). A trunk carries several VLANs (802.1Q tags). STP (Spanning Tree Protocol) prevents loops. A Layer 3 switch can also route.

Digital signature
Hash the message, then encrypt the hash with the sender's private key. The receiver decrypts it with the sender's public key and compares hashes. This proves authenticity, integrity and non-repudiation. To send a secret message instead, encrypt it with the receiver's public key.
PKI & certificates
A Certificate Authority (CA) issues X.509 digital certificates that bind a public key to an identity. Browsers trust root CAs. TLS (the successor to SSL) uses certificates plus asymmetric key exchange, then a symmetric session key for speed.
Encoding ≠ encryption ≠ hashing: Base64 and URL encoding only change the representation and anyone can reverse them. Encryption needs a key to reverse. Hashing can't be reversed at all.

IDS vs IPS
IDS (Intrusion Detection) detects and alerts (passive). IPS (Intrusion Prevention) sits inline and blocks. Both can be signature-based or anomaly-based.
VPN
An encrypted tunnel over a public network. Site-to-site links offices, and remote access connects a user to the office. Protocols: IPsec, SSL/TLS VPN, WireGuard.
DMZ
A buffer zone between the internet and the internal LAN, for public servers (web, mail).
Honeypot
A decoy system that lures and studies attackers.
SIEM
Collects and correlates logs to detect incidents (Splunk, QRadar). A SOC is the team that monitors them.
Endpoint security
Antivirus/EDR, patching, encryption, least privilege, backups (the 3-2-1 rule).
Vulnerability assessment vs penetration testing
A VA finds and lists weaknesses (scanners such as Nessus). A pen test actively exploits them to show the impact. White box = full knowledge · black box = none · grey box = partial. Ethical hacking is authorised testing.
OWASP Top 10
A list of the most critical web app risks, such as broken access control, cryptographic failures, injection, insecure design, security misconfiguration, vulnerable components, and authentication failures.

Networking

  • OSI 7→1: App, Pres, Sess, Trans, Net, DL, Phys
  • PDU: data → segment → packet → frame → bits
  • Hub L1 · switch L2 (MAC) · router L3 (IP)
  • Router separates broadcast domains
  • Private: 10/8 · 172.16–31 · 192.168/16 · loopback 127
  • Hosts = 2ʰ − 2 · /26 = 62 · /27 = 30 · /28 = 14
  • TCP: SYN, SYN-ACK, ACK · UDP: fast, no guarantee
  • 21 FTP · 22 SSH · 23 Telnet · 25 SMTP · 53 DNS
  • 67/68 DHCP · 80 HTTP · 443 HTTPS · 3389 RDP
  • DHCP = DORA · DNS: A, AAAA, CNAME, MX
  • 4xx client error · 5xx server error · 404 / 403 / 500
  • IPv6 128-bit, no broadcast · MAC 48-bit · ARP: IP → MAC

Security

  • CIA: Confidentiality, Integrity, Availability
  • AuthN = who · AuthZ = what · Accounting = log
  • Symmetric AES · asymmetric RSA · hash SHA-256
  • MD5 and SHA-1 are broken · salt your hashes
  • Sign with your private key · encrypt with the receiver's public key
  • MFA = know + have + are (different factors)
  • Worm self-spreads · virus needs a host · trojan disguised
  • Whaling = executives · vishing = voice · smishing = SMS
  • SQLi → parameterised queries · XSS → encode output
  • IDS detects · IPS blocks · WAF protects web apps
  • DMZ for public servers · VPN = encrypted tunnel
  • White / black / grey box = full / no / partial knowledge

Cloud & DevOps

  • IaaS EC2 · PaaS App Engine · SaaS Gmail · FaaS Lambda
  • PaaS: you manage the app and data only
  • Public · Private · Hybrid · Community · Multi-cloud
  • CapEx → OpEx · NIST's 5 characteristics
  • Type 1 hypervisor ESXi/Hyper-V · Type 2 VirtualBox
  • Containers share the kernel · VMs have a full OS
  • Scale up = bigger · scale out = more machines
  • Object S3 · block EBS · file EFS
  • Waterfall sequential · Spiral risk · Agile iterations
  • Scrum: PO, SM, Devs · sprint 1–4 weeks
  • add → commit → push · pull = fetch + merge
  • FROM base · container = running image · pod is the smallest
