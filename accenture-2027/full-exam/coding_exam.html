Note: this simulator runs code in your browser, so DSA supports Python 3 and JavaScript (the real test also offers Java, C++ and C#). Python runs on Skulpt in the browser: the standard built-ins, lists, dicts, sets, strings and collections work, but a few modules such as functools are not available.
