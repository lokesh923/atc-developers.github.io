A
Syllabus · Assessment 1

Behavioural + Cognitive (Gamified)

A1. Psychometric / Behavioural 54 Questions · 20 min No elimination

  • Personality-based situational statements, answered on an agree / disagree scale.
  • Scenarios about workplace behaviour, teamwork, integrity and adaptability.
  • Consistency checks: the same trait is asked in different ways at different points in the test.
How to approach it
  • Answer honestly and stay consistent. Contradicting answers to similar statements are easy to detect.
  • Avoid extreme answers on every statement. Think about how a reliable, team-oriented professional would act.
  • You have about 22 seconds per statement, so don't overthink.

A2. Gamified Cognitive 3 Games · 20 min Elimination round

These games test mental math speed, spatial reasoning and planning under time pressure. According to a previous candidate, 3–4 people at their test centre were eliminated here.

1

Speed Arithmetic

Bubbles show expressions using addition, subtraction, multiplication and division. Work out each result and select the bubbles in ascending order of their values.

15 sec per question~25 questions
2

Pathfinding Puzzle

Change path directions and rotate or move tiles so the path reaches a target point.

~5 min per puzzle
3

Grid Key Collection

On a grid of about 10×10, collect every key and then reach the door. Plan the shortest route before you move.

~5 min~10×10 grid
Worked example · Speed Arithmetic Bubbles: 18 ÷ 3, 4 × 2, 15 − 11, 2 + 3
Values: 6, 8, 4, 5 → click in order: 15 − 11 (4) → 2 + 3 (5) → 18 ÷ 3 (6) → 4 × 2 (8)
Tips for the games
  • Practise mental math daily: tables up to 20, squares up to 25, quick division.
  • In the puzzles, look at the whole board for a few seconds before making your first move.
  • Time pressure is real. If you're stuck, make a reasonable move and keep going.

B1. MS Office Quick Reference

Must-know Excel formulas

  • =VLOOKUP(value, table, col_no, FALSE) finds an exact match and returns the value from column col_no.
  • =IF(A1>=40, "Pass", "Fail") returns one value if the condition is true, the other if it's false.
  • =COUNTIF(A1:A10, ">50") counts the cells that meet a condition.
  • =SUMIF, =AVERAGE, =MAX, =MIN, =CONCATENATE, =LEN
  • Cell references: A1 relative, $A$1 absolute, $A1 mixed.

B2. Pseudocode & Bitwise: Worked Examples

Bitwise operators with x = 5, y = 3

OperationBinaryResult
x & y AND0101 & 0011 = 00011
x | y OR0101 | 0011 = 01117
x ^ y XOR0101 ^ 0011 = 01106
x << 1 left shift0101 → 101010
x >> 1 right shift0101 → 00102

Shortcut: x << n = x × 2ⁿ, and x >> n = x ÷ 2ⁿ (integer division).

Trace this: what is printed?

Integer a = 12, b = 10
a = a ^ b    // a = 0110 = 6
b = a ^ b    // b = 1100 = 12
a = a ^ b    // a = 1010 = 10
Print a, b

Output: 10 12. This is the XOR swap trick, and it comes up often in exams.

How to crack pseudocode without pen and paper
  • Track only the variables that change. Update them line by line in your head.
  • For loops, work out the first two or three iterations, spot the pattern, then jump to the end.
  • Watch for mod (%), integer division, and whether a loop condition is < or <=.

B3. OOPs: The Four Pillars

Encapsulation

Bundling data and the methods that use it inside a class, and hiding internal details (private fields, getters and setters).

Abstraction

Showing only what's essential and hiding how it works, using abstract classes and interfaces.

Inheritance

A child class reuses the properties and methods of a parent class (an "is-a" relationship).

Polymorphism

One name, many forms. Overloading happens at compile time; overriding happens at runtime.

B4. Networking, Security & Cloud Cheat Sheet

OSI model, layer 7 down to 1

Application → Presentation → Session → Transport → Network → Data Link → Physical

Memory trick: "All People Seem To Need Data Processing"

TCP/IP has 4 layers: Application, Transport, Internet and Network Access.

Common protocols and ports

HTTP · 80HTTPS · 443DNS · 53DHCP · 67/68 FTP · 21SSH · 22SMTP · 25Telnet · 23

DNS turns domain names into IP addresses. DHCP gives devices an IP address automatically.

Security basics

  • Firewall filters network traffic using rules. A VPN creates an encrypted tunnel.
  • Symmetric encryption uses one shared key (AES). Asymmetric encryption uses a public and private key pair (RSA).
  • Malware types: virus, worm, trojan, ransomware, spyware, adware.
  • Phishing means fake messages that trick people into revealing data.

Cloud & DevOps

  • IaaS rents infrastructure (AWS EC2). PaaS provides a platform to deploy on (Heroku, Google App Engine). SaaS is ready-to-use software (Gmail).
  • Deployment models: public, private, hybrid, community.
  • CI/CD automatically builds, tests and deploys code. Git handles version control. Docker runs apps in containers.

  • Topics: arrays, strings, hashing, two pointers, basic recursion, sorting-based problems, number logic.

Language availabilityThe official list includes Java, .NET, Python, C++ and C#. One previous candidate saw only Java, Python and C# in their test, so be comfortable in at least one of those three.

Practice problems by topic

  • Arrays: second largest element, move zeros to the end, rotate an array, max subarray sum
  • Strings: palindrome check, reverse words, count vowels, anagram check
  • Hashing: frequency count, first non-repeating character, two-sum
  • Two pointers: pair with a target sum, remove duplicates from a sorted array
  • Number logic: prime check, digit sum, Armstrong number, GCD/LCM

Example: Two-Sum with hashing (Python)

def two_sum(nums, target):
    seen = {}                  # value → index
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
    return []

Runs in O(n) time instead of the brute-force O(n²).

C2. Database: SQL 1 Question

What's asked

  • SELECT with WHERE, ORDER BY, GROUP BY, HAVING
  • Joins (main focus): INNER, LEFT, RIGHT, self-join
  • Aggregates: COUNT, SUM, AVG, MIN, MAX
  • DISTINCT, LIMIT, basic subqueries
Not asked: triggerswindow functionsadvanced SQL

Example: departments with more than 2 employees

SELECT d.dept_name, COUNT(e.emp_id) AS total
FROM departments d
LEFT JOIN employees e
       ON e.dept_id = d.dept_id
GROUP BY d.dept_name
HAVING COUNT(e.emp_id) > 2
ORDER BY total DESC;
JoinReturns
INNER JOINOnly the rows that match in both tables
LEFT JOINAll rows from the left table, plus matches from the right (NULL where there's no match)
RIGHT JOINAll rows from the right table, plus matches from the left
SELF JOINA table joined with itself, for example to find each employee's manager in the same table
RememberWHERE filters rows before grouping. HAVING filters groups after GROUP BY. You can't use an aggregate like COUNT() inside WHERE.

C3. Frontend: HTML, CSS, JavaScript 1 Question

  • Fix or complete the functionality in a given template, similar to the HackerRank React certification style.
  • DOM manipulation, event handling, basic form validation.
  • CSS selectors, flexbox basics, toggling classes. React.js and Vue.js fundamentals.

Example: toggle a class on click (JavaScript)

const btn = document.querySelector("#menuBtn");
const nav = document.querySelector(".nav");
btn.addEventListener("click", () => {
  nav.classList.toggle("open");
});

Example: counter with React state

function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() =>
    setCount(count + 1)}>{count}</button>;
}
Don't take this lightlyThe Frontend question usually needs only small edits to fix the functionality, but you must read the whole template and every instruction carefully. Check element IDs, class names and expected output before you submit.

Section-wise Tips & Examples

A · Always answer in a full sentence

Never give one-word answers. Mirror the question's structure in your answer.

Q: Where is the meeting being held?
✗ "Room 4."
✓ "The meeting is being held in Room 4."

B · Reply politely and professionally

Prompt: "Can you send me the report by today?"
✓ "Sure, I'll share the report with you by the end of the day."

E & F · Grammar focus areas

  • Subject-verb agreement, including as well as, each of, neither…nor
  • Tense usage: simple past vs present perfect
  • Conditional sentences and reported speech

✗ "Each of the students have a laptop."
✓ "Each of the students has a laptop."

G · A simple structure for 45 seconds

  1. Opening: state your view in one line.
  2. Two points: each with a short reason or example.
  3. Closing: sum up in one line.

Use the 30 seconds of prep time to note your two points. Speak steadily rather than fast.

Email Task: Template & Sample

The email must have a proper greeting, a body explaining the situation, a corrective or assurance statement, and a polite sign-off. Write at least 50 words.

Sample task: You missed a team meeting yesterday. Write an email to your manager.

Subject: Apology for Missing Yesterday's Team Meeting

Dear Mr. Sharma,

I am writing to apologise for missing yesterday's team meeting. Due to an unexpected network outage at my location, I was unable to join the call on time.

I have gone through the meeting notes shared by the team and will complete my assigned tasks by Friday. To avoid this in future, I have arranged a backup internet connection.

Best regards,

Interview Preparation

Candidates who clear every assessment move to the final interview. Prepare for both technical and HR questions.

Technical questions

  • Explain your projects: your role, the tech stack, challenges you faced
  • OOPs concepts with real-life examples
  • Basic DBMS (keys, normalisation, joins) and SQL queries
  • Writing simple code: reverse a string, check for a prime, find duplicates

HR questions

  • Tell me about yourself.
  • Why Accenture?
  • Are you willing to relocate anywhere in India?
  • What are your strengths and weaknesses?
  • Describe a time you worked in a team or solved a problem.

4-Week Preparation Roadmap

A balanced plan of about 2–3 hours a day. Adjust it to your strengths, and spend more time on the elimination-heavy Technical round.

Week 1

Foundations

  • MS Office: Excel formulas, Word and PowerPoint features, shortcuts
  • CS fundamentals: data types, operators, control structures
  • Daily: 15 min of mental math
  • Coding: 2 easy array and string problems a day
Week 2

Pseudocode & Networking

  • Bitwise operators, loop and recursion tracing in your head
  • OOPs pillars with examples
  • OSI/TCP-IP, protocols and ports, security basics
  • SQL: SELECT, WHERE, GROUP BY, HAVING
Week 3

Coding Depth

  • Hashing, two pointers, sorting-based problems (Easy/Medium)
  • SQL joins: INNER, LEFT, RIGHT, self-join with subqueries
  • Frontend: DOM, events, React useState, small fixes
  • Cloud models and DevOps basics (CI/CD, Git, Docker)
Week 4

Mocks & Communication

  • Full timed mock tests (45 questions in 45 min)
  • Practise each communication section A–G out loud
  • Write 3–4 professional emails of 50+ words
  • Prepare HR answers and revise your projects

Exam-Day Checklist

  • Mock assessment completed and your system checked
  • Stable internet connection with a backup ready
  • Webcam, microphone and headphones tested
  • A quiet, well-lit room with no interruptions
  • Read every instruction before you start each section
  • Java users: comment out throw new Exception(...)
  • Answer communication Section A in full sentences
  • Stay calm in the gamified round and keep moving
