Before starting

1

It is about the process

You are assessed on how you collaborate with AI, not just on the outcome you achieve.

2

Frame the problem first

Understand inputs, outputs, constraints, and edge cases before giving the prompt.

3

Prompt with intent

Use structured, complete prompts. Vague one-liners like "write the code" won't cut it.

4

Follow the scaffolding

Give clear, correct inputs at each step to unlock the next — and finally code generation.

5

Always review the code

Check and understand the code before submitting it. Here, the AI's code always contains realistic mistakes.

6

Stay within the rules

No phones, no external tools, or discussion. Do not copy sample values.

Practice questions

How this practice platform works

  • The AI Assistant is a practice simulator, not a live AI model. It follows the same scaffolding as the real test: it checks whether your description, data-structure choice and approach cover what matters for the question. It refuses vague or "just give me the answer" prompts, and only generates code once all three steps are done.
  • The generated code is realistic but deliberately contains 2–3 mistakes, like the struct re-declaration seen in the real test. Ask the assistant to refine specific logic by explaining what and why, or fix it yourself.
  • Your browser can't compile code, so the judge recognises the fixes you make and runs a model of your program. The model was checked against real gcc / g++ / javac / python3 output. It works on the assistant's solution: keep edits focused on the logic you are fixing.
  • Your score = test cases (25 marks) + process (25 marks: framing, data structure & reasoning, approach, prompt quality, review & adapt).

Your code, chats, timers and scores are saved in this browser only.
