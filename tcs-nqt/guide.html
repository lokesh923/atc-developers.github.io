Exam Pattern

TCS NQT has two parts. Foundation (Part A) is required for all roles. Advanced (Part B) decides Digital and Prime.

Exam Rules

No section switchingOnce a section ends you cannot return to it.
Question switching allowedMove between questions inside the same section.
No negative markingAttempt every question. A guess costs nothing.
Section-wise timerEach section has its own countdown.
Rough paper allowedKeep a pen and blank sheets ready.
Original Govt ID checkedCarry the original, not a photocopy.
TITA questions"Type In The Answer": no options, you type the value.
Two coding problemsOne Easy, one Medium, 90 min shared.

The section is restructured into three task types: Sentence Completion, Passage Recall (memory based, the passage disappears after 30 seconds of reading) and Email Writing. Every sub-section is timed per question.

Strategy: Verbal is strictly timed per item, so practise speed. Aim for under 25 s per sentence-completion question and write emails with a fixed structure: greeting, purpose, details, action, closing.

Programming Basics

Loops, conditionals, functions, input/output, patterns, number printing, pointers and references

Arrays & Matrix

Rotation, subarrays, prefix sum, rearrangement, 2D traversal (spiral, diagonal), duplicates, kadane

Strings

Palindromes, anagrams, frequency count, substrings, pattern matching, reversal, compression, parsing

Math & Number Theory

Prime, GCD/LCM, factors, Fibonacci, sieve, modular arithmetic, base conversion, Armstrong, perfect numbers

Sorting & Searching

Bubble, selection, insertion, merge, quick sort, binary search, custom comparators, kth element

Two Pointers & Sliding Window

Pair sum, max sum window, longest unique substring, merging sorted arrays

Hashing & Maps

Frequency maps, two-sum, grouping, sets, first non-repeating element

Recursion & Backtracking

Subsets, permutations, N-Queens, tower of Hanoi, combination sum

Stack & Queue

Balanced parentheses, next greater element, expression evaluation, queue via stacks

Linked List, Trees, Graphs

Reverse list, cycle detection, tree traversals, height, BFS, DFS, shortest path basics

Greedy & Dynamic Programming

Activity selection, coin change, knapsack, LIS, LCS, grid paths (usually Medium level)

Bit Manipulation & Misc

Set bits, power of two, XOR tricks, date/time and simulation problems, edge cases

Smart tips

  • No negative marking: never leave blanks.
  • No section switching: finish each section before time ends.
  • TITA questions: practise exact numeric answers.
  • Solve the Easy coding problem fully first.
  • Submit a partial solution rather than nothing.
